Practica 2: Sitio Web e

Objetivo
Desarrollar y publicar un sitio web profesional, responsivo y accesible para un negocio (Montacargas MORO), aplicando etiquetas semánticas de HTML5, diseño moderno con CSS Flexbox y Grid, y buenas prácticas de accesibilidad web.

Tecnologías Utilizadas
- HTML5 Semántico (<header>, <nav>, <main>, <section>, <article>, <footer>)
- CSS3 (Flexbox y CSS Grid)
- Diseño Responsivo (Media Queries / Breakpoints)
- W3C Validators (HTML y CSS)
- GitHub Pages
